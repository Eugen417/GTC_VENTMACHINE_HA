# GTC Ventmachine для Home Assistant

Пользовательская интеграция для управления приточными и приточно-вытяжными установками **Ventmachine** (автоматика **GTC**, контроллеры **Syberia 5 / Оазис v.5**) по протоколу **Modbus TCP**.

## 📥 Установка и настройка

> **⚠️ ВАЖНО:**
> 1. Перед установкой данной интеграции обязательно **удалите или закомментируйте старую YAML-конфигурацию Modbus** для этой вентустановки в файлах Home Assistant (`configuration.yaml` / `packages`).
> 2. **Закройте мобильное приложение GTC**: встроенный контроллер поддерживает **только одно активное соединение Modbus TCP**. Если старый YAML-код или мобильное приложение удерживают порт, контроллер отклонит подключение (`Connection refused`).

[![Open your Home Assistant instance and open a repository maintainer's profile on GitHub.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=Eugen417&repository=GTC_VENTMACHINE_HA&category=Integration)

1. **HACS**: Нажмите кнопку выше или добавьте репозиторий `https://github.com/Eugen417/GTC_VENTMACHINE_HA` в *Пользовательские репозитории (Custom Repositories)* с типом **Интеграция (Integration)**.
2. **Перезапуск**: Перезапустите Home Assistant после скачивания интеграции.
3. **Добавление устройства**: Перейдите в *«Настройки» → «Устройства и службы» → «Добавить интеграцию»*, найдите **GTC Ventmachine** и укажите:
   * **IP-адрес или хост** контроллера (или шлюза RS-485).
   * **Порт Modbus TCP** (по умолчанию `502`).
   * **Slave ID (Адрес устройства)** (по умолчанию `1` — должен совпадать с адресом, заданным в меню пульта).
4. **Изменение параметров**: Вы можете в любой момент изменить IP-адрес, порт или Slave ID через кнопку **«Настроить»** на карточке интеграции без удаления устройства.

## ✨ Возможности версии 1.3.5

* **Нативное управление**: Полноценные сущности `Climate` и `Fan` для интеграции в стандартные карточки Home Assistant, Apple HomeKit и Яндекс Умный Дом (с мгновенным откликом интерфейса и отображением `hvac_action`).
* **Умное автоопределение оборудования и сущностей**: При запуске интеграция опрашивает регистры комплектации (`Type_Dev`, `Fan_Config_2`, `Dev_Keys_2`) и **автоматически скрывает** сущности тех узлов, которых нет в вашей установке (второй вентилятор/вытяжка, водяной калорифер, рекуператор, ротор), оставляя интерфейс чистым.
* **Раздельное управление притоком и вытяжкой**: Отдельные ползунки `Скорость притока` (регистр `32`) и `Скорость вытяжки` (регистр `33`) автоматически активируются для приточно-вытяжных установок (ПВУ) с раздельным управлением, позволяя балансировать воздухообмен в автоматизациях.
* **Стабильный транспорт Modbus TCP**: Постоянное соединение с автоматическим переподключением, чтением подтверждений записи (`0x06`), очисткой буфера, межпакетными паузами `30 мс` для RS-485 и совместимостью со старыми версиями прошивок (`0.95` / `0.102`, `Transaction ID = 0`).
* **Долгосрочная статистика HA**: Все числовые датчики оснащены `device_class` и `state_class: measurement` для построения графиков за длительные периоды.
* **Семантическая индикация аварий**: Все ошибки используют класс `problem` (`device_class: problem`), обеспечивая нативный перевод и цветовую индикацию в истории.

| Имя в Home Assistant | Платформа | Иконка | Описание и диапазон |

## 🔌 Рекомендации по подключению (Ethernet vs RS-485 шлюз)

Интеграция поддерживает два способа подключения к контроллеру GTC:
1. **Через штатный порт Ethernet контроллера** (порт `502`).
2. **Через внешний конвертер RS-485 ↔ Wi-Fi / Ethernet** в режиме преобразователя *Modbus TCP ↔ Modbus RTU* — например:
   * Промышленный модем **[Promodem WiFi-485 AC (PRO271.01)](https://promodem.ru/produkty/s-interfeysom-rs-485/modem-promodem-wifi-485-ac.html)** (устанавливается прямо внутри корпуса ПВУ с питанием 220 В).
   * Конвертеры **Elfin E11 (Ethernet)** / **Elfin EW11 (Wi-Fi)**.

> **💡 Совет из практики:** Если при подключении через встроенный порт Ethernet автоматика периодически перестаёт отвечать на команды или зависает соединение, рекомендуется подключиться к колодке **RS-485** контроллера через внешний шлюз (Promodem или Elfin) с включённым конвертером **Modbus RTU-TCP**.
